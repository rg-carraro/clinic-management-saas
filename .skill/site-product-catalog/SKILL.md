# Skill: Site Product Catalog

Manter uma fonte documentada das funcionalidades para reutilização no site.

## Catálogo
Essencial:
- pacientes/clientes
- agenda
- atendimentos
- financeiro
- pagamentos
- saldo consolidado
- WhatsApp manual
- dashboard
- relatórios básicos

Pro:
- tudo do Essencial
- secretária/recepção
- múltiplos usuários
- papéis/permissões
- gestão de equipe
- múltiplas agendas
- relatórios avançados
- automações
- visão consolidada

## Site futuro
Deve consumir/espelhar catálogo e preços configurados no backend/CMS apropriado, evitando divergência entre marketing e produto.
Registrar toda nova feature com: nome comercial, descrição, tier, status (planned/beta/active), plataformas e entitlement.
