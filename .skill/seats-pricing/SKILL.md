# Skill: Seats & Pricing

## Conceito
Cliente enxerga "profissionais"; internamente usar seats/licenças.

Faixas de referência por profissional/mês:
1 = R$49,90
2–5 = R$44,90
6–20 = R$39,90
21–50 = R$34,90
51–100 = R$29,90
101+ = sob proposta, referência a partir de R$25,90.

A faixa aplica o preço unitário aos profissionais contratados conforme regra comercial vigente.

## Tipos de usuário
PROFESSIONAL: profissional com agenda/atendimentos.
STAFF: secretária/recepção.
ADMIN/OWNER: administração.

STAFF não deve ser automaticamente tratado como seat profissional. Sua cobrança/inclusão dependerá do tier comercial.

## Regras
- preços configuráveis no backend
- manter histórico do preço contratado
- não recalcular contratos antigos silenciosamente
- promoções/cuponagem futuras sem nova versão do app
- acima de 100: fluxo comercial, não preço automático obrigatório
